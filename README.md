TripApp er en React Native-app, der hjælper brugeren med at planlægge en rejse eller dagstur ud fra destination, datoer og interesser.

Projektet er udviklet med Node.js version 22.

```bash
nvm use 22
```
Installer derefter alle projektets dependencies med:

```bash
npm install
```
Start Expo med:

```bash
npx expo start
```
